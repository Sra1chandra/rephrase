# Scan layout

From i-have-adhd, stripped for **the reader of the artifact** (manager, teammate). This is not session chrome. Do not restate "step 3 of 5". Do not add a 2-minute next action for the person chatting with the agent. Do not wait for "stop adhd mode".

The artifact must still be professional STE prose (articles on, no caveman).

## What busy reading needs

1. Working memory is small. Put the point on the first line.
2. Knowing is not doing. If the text is a procedure, the first step must be obvious.
3. Extra branches kill the thread. One topic. Finish it.

## Rules for the artifact

1. **First line is the point.** Status, decision, or the action. Not context. Not "This update covers...".
2. **Number real steps.** One bounded action per step. No step with "and then" twice.
3. **No preamble, recap, or closer.** Delete "Great question", "In summary", "Let me know if you have questions", "Hope this helps".
4. **Cap a visible list at 5.** If the source has more, group. Do not drop facts to hit 5. Split groups.
5. **No tangents.** A second topic waits, or gets its own short section if the user asked for a doc.
6. **Time only if the source has time.** "About 15 minutes", never "soon" / "a bit". Do not invent durations.
7. **Errors: location, cause, fix.** No "uh oh". No drama.
8. **Headings only when they pay rent.** Sentence case. Do not invent Done / Next / Blocked unless the user pasted that format or the source already uses it.
9. **Slack / ping / "short":** fewer sentences. Same facts. Same first-line rule.
10. **Doc / writeup:** as long as the facts need. Still start with the point. Still no recap at the end.

## Pre-send on the artifact

Delete:

1. The first sentence if it announces what the text will do.
2. The last sentence if it recaps or offers more help.
3. Sidebars ("by the way").
4. Hedges that add no uncertainty.
5. Idioms: circle back, looping in, on the same page, moving forward. Use the literal action.

Then: if the reader sees only the first line and the last line, do they know what is true and (if it is a procedure) what to do?
