# AI tells (curated)

Act on a tell in proportion to how rarely a careful writer would do it on purpose. §1-§5: one sighting is enough. Others: act when they cluster, or when they hide the fact.

Fix: state the fact. Do not replace slop with different slop.

## Staging instead of stating

| Id | Don't | Do |
|---|---|---|
| §1 | Not X but Y. It's not X, it's Y. Not X. Not Y. Just Z. | State Y. Keep a contrast only if the reader actually believes X. |
| §2 | One-line closers. Fragments for fake punch. "That's the real win." "Let that sink in." | Cut the closer. Merge fragments into one claim. |
| §3 | Fake profundity. "At its core." "The real question is." "X is the Y of Z." | The specific claim. |
| §4 | Run-up. "Let's dive in." "Here's what you need to know." "Here's the thing." | Start with the point. |
| §5 | Arguing with no one. "To be clear." "I'm not saying." "You might think." | Delete unless someone in the source made the objection. |
| §26 | Re-explain what the reader already knows before the decision. | Lead with the decision. Keep the one fact they lack. |

## Rhythm and decoration

| Id | Don't | Do |
|---|---|---|
| §6 | Forced triads. "fast, reliable, and scalable" as a claim. Rule of three stacked. | Keep three only if there are three real parts. |
| §7 | Same sentence opening repeated (It... It... It...). Weak alone. | Merge or start with the action. |
| §8 | Em dash, en dash, ` -- `. | Period, comma, colon, or parentheses. Never a dash in output. Leave code and URLs. |
| §9 | Stacked hedges. "could potentially", "might arguably". Weak alone. | One hedge, only if the source supports it. |
| §19 | Bold label on every bullet. Bold for emphasis. | Bold only for UI labels or warnings. |
| §20 | Title Case headings. Emoji. Arrow headings. | Sentence case. Name what the section holds. |
| §21 | Curly quotes in Markdown. Weak alone. | Straight quotes. |

## Inflation and borrowed authority

| Id | Don't | Do |
|---|---|---|
| §12 | Stock AI words: delve, leverage, robust, seamless, crucial, pivotal, showcase, underscore, tapestry, testament, landscape, additionally, utilize, meticulous, intricate, vibrant, foster, streamline, harness. | Plain word. See swaps below. |
| §13 | Inflated stakes. "Pivotal moment." "Broader shift." "Lasting legacy." | The concrete fact. End on it. |
| §14 | Vague link. "associated with", "tied to". | Name the relation the source gives. Do not invent one. |
| §15 | Trailing `-ing` analysis. "highlighting", "ensuring", "fostering", "reflecting". | Cut the rider unless the source states that claim. |
| §16 | Sales copy. groundbreaking, stunning, world-class, nestled, rich heritage. | What it is and does. |
| §17 | Vague authority. "experts argue", "industry reports", "observers". | Name who said what, or cut it. Never invent a source. |
| §18 | Copula dodge. serves as, stands as, marks, represents, boasts, features. | is, are, has. |

## Chat and draft leftovers

| Id | Don't | Do |
|---|---|---|
| §22 | Great question. I hope this helps. Let me know if. Would you like. | Remove the wrapper. |
| §23 | As of my last update. Details are limited. | Say what the source does not show, or cut it. |
| §24 | Heading then first line repeats the heading. | Delete that line. |
| §25 | Writing about the document. "The table below compares." | Write about the subject. |
| §27 | Signposted conclusion. In conclusion. To sum up. To recap. | Stop when the last fact is down. |
| §28 | Compulsive counting. "Five things we wish to discuss." | List them. Do not announce the count unless the count is the fact. |
| §29 | Premise stacking. A paragraph of evidence, then the question already answered. | Ask or state once. |
| §30 | Reasoning leak. Narrating what the text is about to do. | Do it. |
| §31 | Synonym cycling. dashboard, then interface, then portal. | One name. |
| §32 | Think of it as... It's like a highway for data. | The actual mechanism. |
| §33 | Quietly / deeply / fundamentally / remarkably as fake weight. | Delete the adverb, keep the verb. |
| §34 | False range. "from innovation to implementation to cultural transformation." | Name the items. |
| §35 | Despite its challenges... continues to thrive. | The actual problem, or cut. |

## Word swaps

| Don't | Do |
|---|---|
| utilize | use |
| leverage | use |
| commence | start |
| prior to | before |
| in order to | to |
| facilitate | help / make possible |
| implement (when you mean do) | do / add / ship |
| additional | more |
| numerous | many, or the number |
| subsequent | next / later |
| terminate | stop / end |
| endeavor | try |
| regarding | about |
| assist | help |

Keep a word when the swap would change the meaning (legal "terminate", product name "Leverage").
